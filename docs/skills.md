# 技能（Skill）

技能是工作流程、规范和参考资料；工具负责实际操作。技能不会扩大模型的权限，也不会自动运行附带脚本。本版复用 Spring Boot、SQLite、现有模型、上下文引擎和命令沙箱，无需另配 Embedding。

## 使用入口

- 设置 → 技能：新建、导入本地目录或 ZIP、编辑 SKILL.md、启停、自动匹配、卸载。
- 聊天框输入 `/` 搜索已启用技能，用方向键和 Enter 选择，最多 3 个；选择后输入任务再发送。选择是独立的 skillIds 字段，不是通过伪造提示词触发权限。
- 聊天框“自动匹配”仅控制本轮。发送成功后清空本轮选择，并恢复自动匹配默认值；单个技能的自动匹配开关持久保存。
- 对话显示实际加载的名称、版本和原因；“本轮上下文”显示加载记录和正文估算 token。
- 原扩展页转为入口说明，预置需求文档、代码审查、浏览器验证迁移为真实技能。旧启用配置在首次迁移时保留；未曾启用的预置技能默认关闭。浏览器验证技能仅描述流程，没有凭空增加浏览器工具。

## 包格式

```text
review-skill/
  SKILL.md
  references/   # 参考资料
  templates/    # 输出模板
  scripts/      # 可选脚本
```

SKILL.md 示例：

```markdown
---
name: code-review
description: 代码审查 code review 安全缺陷 回归检查
version: 1.0.0
---

先确认审查范围，读取真实 diff 和相关文件。
按 references/review-guide.md 的检查项审阅。
报告包含位置、触发条件、影响、建议和未验证事项。
```

YAML 使用安全解析器；名称最多 80 字，描述最多 500 字。导入包最多 200 个文件、单文件 200000 字节、总大小 2000000 字节；路径最多 10 层。拒绝 ZIP 路径穿越、符号链接、重复路径和不支持的条目；目录导入拒绝链接和 Windows 重解析点。每个 ZIP 只能包含一个 SKILL.md，可有一层包裹文件夹。

全局技能复制到应用数据目录的 skills/；项目技能复制到 `.dongran/skills/<安装ID>/`。导入后与原目录解耦，卸载只删除已安装的包，保留原始导入目录和任务产物。项目中的技能目录可以提交 Git；其他成员打开项目后使用“扫描项目目录”注册，不会直接运行脚本。扫描注册的包也属于可卸载的技能目录。

项目同名技能覆盖全局；即使项目条目被禁用，也不会偷偷回退到全局。卸载项目条目后全局条目重新生效。已注册条目不会在扫描时重置启停状态。

编辑器只编辑 SKILL.md；附件可在显示的安装目录中维护。包内任何文件变更都会使校验失效，打开编辑器审阅并保存后重新记录包哈希。编辑时不能直接改名；需以新技能导入。版本和全包哈希绑定本次加载及脚本执行，版本字符串由作者维护。

## Agent 链路

SkillResolver 在当前有效范围内通过本地词项匹配筛选最多 5 个候选；只传名称、描述和版本，由主 Agent 判断适用性后调用 load_skill。这里是规则召回加模型选择，并非已训练的专门意图分类模型；最终效果受描述与模型工具能力影响。

用户显式选择的技能会直接加载，不依赖模型是否主动调用工具；自动匹配依赖模型正确使用工具。关闭自动匹配的技能只接受显式选择。没有相关技能时不新增技能提示词和工具定义。

- load_skill：验证启用范围和包哈希，加载正文、资源清单并记录来源。
- read_skill_resource：读取已加载技能的文本参考资料，每页 8000 字符。
- run_skill_script：校验当前版本、脚本路径和参数，审批后再次核验，在项目命令沙箱运行。

正文首段最多 8000 字符，完整内容存为证据，可分页读取，避免一次塞入全部资料。上下文预算继续由 ContextEngine 控制，必要内容过大时明确失败。子 Agent 不继承主 Agent 的整套技能正文，只按分配子任务获得相关候选与独立加载记录；读取资料或执行脚本要求当前角色在本轮加载过该版本。

## 脚本边界

脚本必须位于 scripts/，需要当前项目，并受 Agent 的角色工具权限、只读模式和审批约束。支持已安装的 Python、Node，以及 Windows PowerShell / Unix sh；不自动安装运行时或依赖。

脚本及其包资源复制到隔离副本的 `.dongran/skill-run/`。通过独立 argv 传递参数，不拼接用户参数成 Shell 命令。Windows PowerShell 使用本次进程的 ExecutionPolicy Bypass 运行用户批准的脚本，不修改宿主机策略；AppContainer 隔离和禁止联网仍生效。沙箱不可用则拒绝，不降级到本机终端。

成功时沿用项目差异校验与回写规则；技能包所在 .dongran 不参与回写。脚本可能依赖沙箱不可访问的系统资源，这时会报告真实失败。macOS 的原生沙箱尚未启用，因此不能宣称其技能脚本已经可用；Linux 需要本机验证。

## 接口

- GET /api/skills?projectId=...：全局和当前项目目录及实际生效状态。
- POST /api/skills：创建（content、projectId）。
- POST /api/skills/directory：目录导入（path、projectId）。
- POST /api/skills/zip：multipart file 和可选 projectId。
- POST /api/skills/scan：扫描当前项目目录。
- GET /api/skills/{id}：正文、文件清单和磁盘哈希。
- PUT /api/skills/{id}：编辑正文，携带 expectedHash。
- POST /api/skills/{id}/state：enabled、autoMatch。
- POST /api/skills/{id}/refresh：审阅后的重新同步入口。
- DELETE /api/skills/{id}：卸载。
- 创建任务/追加消息支持 skillIds、autoSkills。

V010 保存技能元数据、每轮选择和历史加载记录；卸载不会抹除既有任务的使用记录。

## 验证与未包含范围

SkillIntegrationTest 验证导入安全、作用域、关闭自动匹配、按需加载、版本校验和扫描。SandboxIntegrationTest 验证真实 Windows 沙箱中的脚本、参数不被当作命令及包目录不回写。verify-skills.cjs 使用临时数据库及本地合成模型验证完整 UI 链路，不发送用户资料到外部模型。

本版不包含在线市场、Git 远程安装、任意第三方界面插件、自动更新回滚或附件二进制预览。关闭/卸载不撤回模型已经接收的内容；后续轮次重新组装时按当前状态处理。
