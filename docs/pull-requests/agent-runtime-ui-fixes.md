# 修复续聊权限模式、模型响应处理及工作台交互

## 问题与行为

续聊原先未传递用户新选择的权限模式，导致界面显示与后端执行不一致。现在每轮传递并保存执行模式；允许项目内修改时不重复确认普通文件写入与沙箱命令，仅规划不提供执行工具。技能脚本、宿主机 Git 和外部连接仍保留独立审批。

模型在正文输出 DSML 工具协议时，响应会被拒绝并要求重新生成；仅规划明确输出 Markdown 方案。length 截断重试会增加输出预留并同步调整上下文预算，截断调用不执行。相同工具及参数第二次调用提示复用结果，第三次停止，16 轮硬上限仍保留。

技能选择器支持点击展开、搜索及启用后选择；自动匹配开关与技能入口放在一起。修复深色主题回到最新按钮，增加产物面板进出动画，移除设置页左下品牌区域。团队数量从固定 4 改为根据当前任务消息和实时事件中的角色统计，空闲显示主 Agent 1。

## 限制

本次未调用用户配置的云端模型，不能保证第三方供应商的协议兼容性。重复检测按工具名与原始参数字符串计数，不等同于完整的语义进度判断；尚未实现自动分阶段续跑或工具结果缓存。团队数量表示已观察到的参与角色数量，不是当前并发进程数。浏览器视觉与完整交互未在此次提交前重新回归。

个人配置、数据库、密钥及本地运行日志不在提交范围内。
