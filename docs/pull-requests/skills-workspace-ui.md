# 新增全局与项目技能系统，优化工作台交互

## 变更

将原扩展中的预置工作流落地为可管理的 Skill 包。用户可以在设置中新建、导入本地目录或 ZIP、编辑、启停及卸载全局或项目技能，在聊天框通过 `/` 显式选择，或由本地候选匹配与 Agent 按需加载。项目同名技能优先，加载记录包含版本、包哈希与使用原因，并接入上下文检查。

技能资源分页读取，脚本经一次具体审批后通过现有项目沙箱执行；拒绝审批不启动脚本。导入校验路径穿越、符号链接、重复文件及大小限制，执行前核验包内容。SQLite V010 保存技能、任务选择与加载记录，预置技能按原启用状态迁移。

工作台同步优化滚动条、左下角账户/设置菜单和侧边栏滑动动效。
