# Dongran Work 0.1.0-beta.1 · Windows x64

首个 Windows 测试版，包含 Agent 对话、项目工作区、知识库、技能、记忆、模型配置、Git 与终端。

## 安装

下载 Windows x64 setup.exe 并安装，无需安装 Java、Rust 或 Docker。首次启动需要 Microsoft Edge WebView2 Runtime；安装器可引导下载安装。模型服务和 API Key 由用户自行配置。

此测试版尚未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。请核对下载来源及 SHA256SUMS.txt。

## 数据与限制

- 桌面版数据位于 Windows 用户应用数据目录的 com.dongran.work 下，与开发版 .dongran-work 目录分开。安装包不包含开发者配置、记忆或密钥。
- 支持 Windows x64，其他系统不在本次发布范围。
- 沙箱不可用时不会自动降级到宿主机执行；项目命令依赖的开发工具仍需用户自行安装。
- 此 beta 不含自动更新，升级请下载安装包；升级前建议备份用户数据。
- 云端模型兼容性、长任务稳定性仍需持续验证。
