# Dongran Work 0.2.0-beta.1 · Windows x64

本版更新项目工作区、多 Agent 协作、技能演进与桌面窗口体验。

## 更新

- 工作区按项目分组，支持折叠、项目任务切换及未关联项目对话。
- 多 Agent 使用事件驱动 DAG 调度，子节点结构化回传结果，按依赖并发执行并动态追加验证节点。
- 成功与失败任务后台生成技能改进候选，支持人工审核、模拟评测报告、发布与版本回滚接口。
- 技能页面展示自动生成开关、提炼记录、评测历史和已发布技能入口。
- 一体式桌面标题栏，支持拖动、双击最大化、最小化、还原和关闭。

## 安装与数据

下载 Windows x64 setup.exe 安装，内置 Java 和沙箱辅助程序，无需安装 Rust 或 Docker。模型服务由用户配置。升级保留本机资料，安装包不包含开发者的账户、配置或密钥。

## 已知限制

- 本版为 Windows x64 测试版，安装包尚未签名。
- Skill 评测为静态检查与模型模拟评审，不能替代真实执行测试。
- DAG 节点结果和跨节点共享状态仍需进一步验证。
- 不含自动更新，后续升级需下载安装包。
