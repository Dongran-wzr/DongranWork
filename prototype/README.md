# Dongran desktop prototype

面向研发与产品部门的本地项目 Agent 工作台。打开 `index.html` 即可体验，不需要启动服务。

仅面向桌面端，支持 1024px 及以上宽度的桌面窗口；不提供移动端入口或手机布局。

## 已对齐的需求

- 选择本地目录作为项目入口。
- 一个主 Agent 统一接收任务，按需调度产品、开发、测试 Agent。
- 覆盖需求文档、代码修改、运行验证。
- 视觉采用用户确认的 ChatGPT / Codex 中性风格：灰白桌面外壳、深灰文字、宽侧栏、白色工作区和底部宽输入框；绿色主要保留在活动点阵和状态信息。

## 原型入口

- 初始页面：打开本地目录、进入演示项目。
- 演示项目：成员权限管理任务，展示需求、代码差异、执行授权与测试报告。
- 新建任务：输入任务、生成演示计划、停止执行、继续补充需求。
- 右侧面板：文档编辑与文本导出、代码差异、运行结果、项目文件。
- 其他交互：任务搜索、附件选择、收起面板。
- 左侧主导航新增知识库、定时任务。两者使用独立工作区页面，返回后保留任务内容、输入草稿、产物面板和终端状态。
- 知识库为待接入占位页，展示当前项目；资料管理、上传与检索等待后端实现。
- 定时任务支持本机保存、新增、编辑、删除确认、启用／暂停、搜索和状态筛选，支持全局／项目范围以及每日、每周、单次计划。频率和范围使用自绘下拉菜单，弹窗沿用现有动效。
- 左下角齿轮打开完整设置界面，支持常规、外观、模型、Agent、执行权限、终端、快捷键和数据管理。
- 账户设置支持昵称、职位／团队、简介及头像上传。头像支持 PNG／JPEG／WebP，最大 5 MB，可预览裁切和缩放；保存后即时同步左下角账户区与任务对话，支持移除头像，本机保存并在刷新后恢复。
- 设置支持搜索、自动保存至本机、分类恢复默认、配置导入与导出。返回应用会保留项目、任务、输入草稿和终端状态。
- 可即时调整浅色／深色／跟随系统主题、界面密度、字体、侧栏宽度、点阵显示、工具记录展开、发送方式、快捷键和终端字号／高度。
- 外观支持中性、森林、海洋、自定义配色，提供强调色色板和 HEX 输入，可命名保存、切换和删除主题。
- 记忆区分全局与项目，支持搜索、增删改、清空确认。项目可独立启用记忆并选择是否继承全局记忆；恢复设置默认值及导入不含记忆字段的旧配置会保留记忆条目。新任务记录适用记忆的快照，自动提炼仍待接入。
- 扩展管理提供已添加／可添加列表、详情、启停和移除；钩子支持触发事件、命令、超时、失败策略及编辑删除；连接支持 MCP HTTP／SSE 和 GitHub 地址配置。
- Git 与工作树配置包含基准分支、分支前缀、提交格式、任务隔离、工作树目录、初始化命令和清理策略。
- 桌面宠物提供三种机器人形象，可配置名称、大小、透明度、活动程度、停靠和勿扰；工作台内支持拖动、状态互动与关闭。设置页隐藏悬浮宠物。
- 右上角终端按钮：打开独立底部终端，支持清空、展开、关闭、命令历史与演示命令输入。
- 桌面模式加载可选 `backend-client.js`：后端可用时自动建立本机会话并暴露 REST/SSE 客户端；直接打开 HTML 时继续使用原型本地数据。
- 产物面板默认收起，通过产物条目或右上角面板按钮打开。
- 首页热力图由前端 DOM／CSS 渲染 28 周、196 个日期格子，支持日期与任务数提示、键盘焦点和深浅色主题，不使用热力图贴图。发送新任务会累加项目活动，并汇总到首页，活动记录保存在本机；没有真实记录的首页／演示项目显示已标注的示例数据。
- 二级窗口支持淡入、位移与缩放动效；关闭时平滑淡出，并遵循系统减少动态效果设置。
- 权限、模型、设置与视图使用统一自绘菜单，支持方向键、Home/End、Escape、点击外部关闭和屏幕边界定位。
- 顶部文件、编辑、视图、帮助菜单采用紧凑单行分组、分隔线和灰色悬停态，支持展开时悬停切换及左右方向键切换。

## 边界

这是交互原型。Agent 回复、代码修改与测试结果均为演示数据，没有连接模型、写入项目文件或执行真实测试。终端仅支持固定的演示命令，不会执行系统 Shell。模型、网络和真实执行策略配置为后续接入预留。设置通过浏览器 localStorage 持久保存；任务和文档编辑仍只保留在当前页面会话。附件只展示选择状态，未发送或解析。

目录选择优先使用浏览器只读目录接口；不支持时使用目录文件选择器。后者无法选择空目录。真实桌面版本可改用原生目录接口。

扩展、钩子、连接、Git 和工作树当前只管理配置，不安装扩展、发送网络请求、执行命令或修改仓库。桌面宠物仅显示在应用内。文件目录接口使用目录句柄身份保存项目 ID，同名目录不会共用记忆；浏览器降级文件选择器无法提供稳定目录身份，每次选择会分配新 ID。演示项目拥有固定 ID，项目记忆可跨刷新保留。

知识库不产生模拟资料或检索结果。定时任务仅保存在本机 `dongran.schedules.v1`，使用系统当前时区，不触发 Agent、命令或后台调度；实际执行等待后续接入。

## 验证与截图

执行 `node verify.cjs` 进行浏览器交互检查并生成截图。脚本使用本机 Microsoft Edge；其他环境需要调整浏览器路径。

执行 `node verify-settings.cjs` 检查记忆范围隔离、继承、任务快照、扩展／钩子／连接管理、主题保存、桌宠画布与动画、拖动、勿扰、配置持久化和桌面布局。

执行 `node verify-account-activity.cjs` 检查日期热力图渲染、任务统计、项目隔离、账户资料实时同步、头像裁切与异常上传、本机持久化和桌面布局。

执行 `node verify-workspace-pages.cjs` 检查侧栏导航、知识库待接入状态、定时任务配置及持久化、返回后的任务与草稿保留，以及桌面窗口布局。
